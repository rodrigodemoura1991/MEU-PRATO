# Meu Prato

PWA mobile-first para estimar calorias e macronutrientes de refeições usando foto + peso total.

## Versão 1
- Foto pela câmera ou galeria
- Peso total em gramas
- Ajustes de refeição e proteína
- Estimativa de kcal, proteína, carboidratos e gordura
- Histórico local de até 30 refeições
- PWA com suporte offline básico

## Próxima etapa
Integrar análise visual real para identificar os alimentos da foto e estimar as porções individualmente. A estimativa atual é propositalmente apresentada como estimativa e não como análise automática da imagem.

Atalho de complemento: whey e leite desnatado para facilitar o registro do café da manhã.
